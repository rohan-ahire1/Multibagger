# SEPA Backtest Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a local, read-only backtest engine for persisted `BREAKOUT` signals, expose it through `sepa backtest`, and surface the results in the Streamlit UI.

**Architecture:** The backtest flow should stay separate from the scan engine and consume persisted scanner outputs rather than recomputing signal logic. A new `backtest` package will simulate fills and exits from stored signals plus Parquet OHLCV, then feed summary metrics and trade tables to both the CLI and the UI.

**Tech Stack:** Python 3.12, Polars, DuckDB, Typer, Streamlit, Plotly, Pytest
