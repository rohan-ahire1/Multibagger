# SEPA Local UI Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a local Streamlit UI, persist ranked daily watchlist candidates during scan, and expose a `sepa ui` command that launches the app.

**Architecture:** The scan pipeline remains the single source of truth for alert and watchlist logic. DuckDB stores run logs, signals, and daily watchlist candidates, while the UI reads DuckDB plus Parquet through small helper modules and renders Plotly charts with signal overlays.

**Tech Stack:** Python 3.12, Polars, DuckDB, Typer, Streamlit, Plotly, Pytest
